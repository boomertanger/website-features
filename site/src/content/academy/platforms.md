## Ch 1 · Twitch

Mod tools from any message (click a name): delete, timeout, ban. Commands work too: `/timeout name 300`, `/ban name`, `/unban name`. Mod View gives you the chat, the activity feed and AutoMod's held messages in one place. AutoMod holds risky messages for you to approve or deny. Shield Mode exists for raids; only the Captain switches it on.

## Ch 2 · YouTube (two chats)

When Boomer streams on YouTube from his phone there are two broadcasts, landscape and vertical, each with its own chat. You're added as a moderator of each broadcast when the stream starts (Mod Machina does this for scheduled leads). From a message's menu: remove, put user in timeout, hide user on the channel. "Held for review" messages need a yes or no. The Mod Deck shows both YouTube chats side by side; on your phone, use the YouTube app on the vertical stream.

## Ch 3 · TikTok

TikTok LIVE moderators are added by Boomer in the app (Mod Machina keeps a checklist; there's no way to do it automatically). Long-press a comment to mute (choose a length), block or report. Keyword filters catch the worst. TikTok has no chat feed the site can show, so the Deck links out.

## Ch 4 · One crew, every chat

Use the same ladder everywhere, even where the buttons differ. Post your chat's check-in code when you open, and every 20 minutes or so. Nudge people toward the other chats when a Chat Game clue drops there.
