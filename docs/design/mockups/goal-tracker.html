Recommendation: Option 1, Level select

It reads like a game's world map, which is your audience's native language, and it answers the two questions members actually have at a glance: where are we, and what's left before the boss. The mascot standing on the current level is the one memorable moment on the page; everything around it stays quiet.

  • Option 2 (The climb) is more dramatic, but stacking levels upward makes time read bottom-to-top, which is harder to scan, and it needs the side panel to make sense on desktop.
  • Option 3 (Phase board) shows the most at once, but it looks like a project board. Great for your admin page, flat for a fan page.
  • Level select works on phones as a vertical path with the same nodes, so there's one component (.bt-road) to add to the kit.

New kit pieces from this mockup: .bt-road (level select) and .bt-tree (admin rows). Everything else is existing bt-ui: the How it works layout and side menu, chapters, badges, meters, chips, page tabs, the gate, buttons, the dialog and the BOOMBOT FAQ.
