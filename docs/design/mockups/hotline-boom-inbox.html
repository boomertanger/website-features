What's real here. All kit: .bt-topbar, .bt-wordmark--power (W5 Dial-up), .bt-seg-nav tabs, .bt-title, .bt-readouts, .bt-sortbar with .bt-chip, .bt-search, .bt-row--clickable rows, .bt-badge status colours (New blue, Open teal, Waiting gold, Done lime, Spam gray), .bt-composer, .bt-history, .bt-notice, .bt-admin-panel and .bt-admin-tag, .bt-section-head, .bt-stamp, .bt-empty with the mascot, the modal and the toast. Nothing new for the kit. Feature CSS only for the switchboard lamps, the line keys, the source bars and the compose tabs.

Try it. Switch the Viewer to the admin: Business, Private matter, Report a person and the name-checked message disappear completely (no counts, no hints), and the Settings tab goes. Open the @spookycat message as the owner to see the name check. Tap a lamp to filter by line. Reply to a message (the REPLIED stamp, the toast, the status moves to Waiting), switch the composer to Internal note, or, as the admin, use "Owner only" on a team message.
