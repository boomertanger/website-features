1. Wordmark icon

CLOUD + accent STASH on .bt-wordmark--power. Each icon rests until hovered or focused (touch screens play it once as it scrolls in). The accent lights gold like every other feature. The second column is held in its powered-on state so you can compare without hovering.

I1

Storm stash

The old icon's three storage bars, now inside the cloud. Power on: rain falls and the bars light gold one after another.

I2

Rain gauge

A cloud over a little rain gauge with the pause mark on it: the page's job in one picture. Power on: it rains, the level rises past the mark and the mark lights.

I3

Cloud drawer

A cloud sitting on a filing drawer: the stash itself. Power on: it rains, the drawer slides open and a gold file tab peeks out.

Recommendation: I2, Rain gauge.It's the only one that says what the page is for (watching a level), and its gauge, pause mark and colours match the usage meter and the hero, so the whole page tells one story. I1 keeps continuity with the old icon but reads as "server"; I3 is charming but says "files", which every storage icon says.

2. Hero scene

The tool page's hero: title, one status line and a small scene that reacts to usage. Switch Usage in the bar to see Healthy, Uploads paused and Over limit (the rain gets heavier, the level crosses the gold pause mark, then spills red).

S1

Three gauges

The cloud rains into one gauge per feature, filled by how much each stores. The mascot peeks in from the side.

S2

One big gauge

One gauge with the pause mark, filled to this month's usage, and the mascot standing beside it.

Recommendation: S2, One big gauge.The first question on this page is "are we OK?", and S2 answers it at a glance in the same colours as the badge. S1's per-feature split repeats the Recorded by feature card, and it measures storage, which is the smallest part of the usage.

3. The tool page, /admin/stash

Everything works: click a file row for its details, Purge to see the confirmation and the row fall away, the counts in Loose ends to filter, Add rule or Edit for the dry run, Scan now, and the tabs in P2. Switch Seen as to A1 Steward to see the safety net: Purge, Add rule and Run the sweep are disabled with "Needs the owner or an Overseer", and a rule can only be switched off.

P1

One screen

Everything on one page: files and rules in the wide column, usage, loose ends, features, sweep, settings and activity in the side column.

P2

Overview and tabs

Overview answers "are we OK?" (usage, loose ends, features, last sweep and the newest files). Files, Rules and Activity are one tap away, each a short page with one job. The tab is kept in the address (?tab=files).

Recommendation: P2, Overview and tabs.Most visits are a glance at the status, and P2 shows that without scrolling past 556 files. On phones P1 becomes a very long stack; P2 stays short. Every action is still at most one tap away, and the loose-end counts jump straight to the filtered Files tab.

4. File rows

The same files as a table and as rows. Private files never show a thumbnail in the list; their preview is a signed link opened on request (and logged).

F1

Table

The legacy layout on the kit's .bt-table: dense and easy to scan by column, but it scrolls sideways on phones.

F2

Rows

The kit's .bt-row with the neon hover: a thumbnail (or the private lock), the item it belongs to as the title, the file name, feature, kind and age, then size, status and actions. Restacks on phones.

Recommendation: F2, Rows.The title is the thing you recognise (the bug or the game), not a file id, and a row reacts like every other list on the site. It reads on phones without sideways scrolling.

9. Kit pieces and your reply

Three proposed additions to shared/bt-ui.css, the UI kit page and design-system §5. Everything else on these screens is already in the kit or in Cloud Stash's own CSS (the icon, the scenes and the page layout).

.bt-notice--warnThe gold notice next to --error and --ok, for "Uploads paused" and "Usage is out of date". With .bt-notice--row for a one-line notice with a button.
.bt-file-thumbA 52px file tile: an image, or --locked for a private file (lock and "Private", never the picture). The name avoids the existing lightbox .bt-thumb.
.bt-meter--stackThe kit's meter split into segments (.bt-meter-seg with --c) plus .bt-meter-keys, for storage, bandwidth and transformations.
